## 1. 먼저 결정할 것 — 언제 배포할지 (중요)

앱은 웹사이트를 그대로 띄우지 않고 **`https://www.yume-reamer.com/app/`** 을 엽니다.
이 경로는 지금 **운영 서버에 없습니다.** `store-build` 브랜치를 머지하고 배포해야 생깁니다.

**PG(카드사) 심사가 진행 중이라 오늘은 일부러 배포하지 않았습니다.** 배포는 서버를 다시
띄우는 일이고, 심사자가 그 순간에 결제 페이지를 보고 있으면 실패로 기록될 수 있습니다.

두 가지 길이 있습니다.

| | 언제 | 어떻게 |
|---|---|---|
| **A. 심사 끝난 뒤(권장)** | PG 결과가 나오면 | `git checkout master && git merge store-build && git push` → 자동 배포 |
| **B. 오늘 꼭 올려야 하면** | 심사자가 안 볼 시간대(새벽) | 같은 명령. 배포 후 `/`와 `/app/` 둘 다 열어 확인 |

> 웹 화면은 이 머지로 **바뀌지 않습니다.** 확인했습니다 — 요금제 창·크레딧 화면 모두 그대로이고,
> 새로 생기는 것은 `/app/` 경로 하나뿐입니다.

배포한 뒤 확인:

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://www.yume-reamer.com/app/   # 200이어야 함
```

## 2. 플레이 콘솔 계정 (제가 못 하는 일)

1. https://play.google.com/console → 개발자 등록 (**1회 25달러**)
2. **개인 vs 조직**을 고릅니다. 이게 출시 속도를 가릅니다.

| | 개인 계정 | 조직(사업자) 계정 |
|---|---|---|
| 필요한 것 | 본인 인증 | D-U-N-S 번호(무료, 1~2주) |
| 정식 출시 조건 | **테스터 12명이 14일 연속 비공개 테스트** | 없음 |
| 판매자 표시 | 정원영 | REAMER |

**사업자등록이 있으니 조직 계정을 권합니다.** 개인으로 가면 14일이 더 걸립니다.
개인으로 간다면 오늘 중에 테스터 12명(지인 구글 계정)을 모아 두세요.

## 3. AAB 만들기 (Codemagic)

1. https://codemagic.io 가입 → `PandawavePANA/yume` 연결 → 유형은 `codemagic.yaml`
2. Team settings → Code signing identities → **Android keystores** → Add
   - 파일 `android-signing/yume-upload.jks`
   - 비밀번호·별칭은 `android-signing/README-업로드키.txt`
   - **Reference name: `yume_upload_key`** (철자 그대로)
3. 워크플로 **유메 Android (플레이스토어)** → Start new build (약 10분)
4. Artifacts에서 `app-release.aab` 내려받기

> 로컬에서는 못 만듭니다 — 이 PC에 자바와 안드로이드 SDK가 없습니다(확인함).

수수료가 없습니다. **앱에 "웹에서 결제하세요"라고 적는 것은 규정 위반**이라, 파는 길을 아예
보여주지 않는 지금 방식이 안전합니다.
