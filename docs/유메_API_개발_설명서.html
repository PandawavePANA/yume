1. 서비스 개요

유메(YUME)는 ChatGPT, 클로드, 제미나이 등 AI가 답변한 내용 속 사실 주장을 실시간으로 검증해주는 팩트체크 서비스입니다. 법률·의료·금융·역사·과학 등 도메인을 가리지 않고, AI 답변을 그대로 붙여넣으면 각 주장을 확인됨(confirmed)/사실과 다름(false)/판단 보류(uncertain)로 판정하고 근거 출처를 함께 제시합니다.

  • 웹 서비스 — 누구나 무료로 하루 5회까지 사용, 결과 화면에서 개별 주장과 전체 총평을 확인
  • 카카오톡 채널 — 카카오 i 오픈빌더 스킬로 연동, 대화 중 "검증해줘"라고 요청하면 검증 대시보드 링크를 발급
  • 검증 API (v1) — 외부 서비스가 유메의 검증 엔진을 직접 호출할 수 있는 개발자용 API (본 문서 4장)
  • 관리자 대시보드 — 운영자가 사용 현황을 모니터링하는 내부 페이지 (본 문서 5장)
현재 단계는 프로토타입입니다. 결제(구독/토큰 충전)는 실제 PG 연동 없이 데모로만 동작하며, 모든 사용량 데이터는 서버 메모리에만 저장되어 재배포 시 초기화됩니다.

3. 코드 구성 (server/*.js)

파일역할
index.jsExpress 앱 진입점. 라우트 등록, 정적 파일 서빙(dist/), 웹사이트용 IP 기반 무료 한도 적용.
claude.jsAnthropic Messages API 호출 전담. AI 답변에서 사실 주장 추출(extractAndVerify), 법률 주장 웹 검색 폴백(verifyLegalClaimViaWeb), 일반 대화(chatReply).
legalPipeline.js법률(domain==="법률") 주장만 골라 법제처 공식 데이터로 재검증. 조문/판례를 특정 못하면 웹 검색 폴백으로 넘겨 "확인 불가"로 끝내지 않는다.
lawApi.js법제처 국가법령정보 공동활용 Open API 클라이언트 (조문 검색·본문 조회, 판례 검색·상세 조회).
overallVerdict.js개별 주장 판정 배열로부터 "전체적으로는 맞지만 이 부분은 틀렸다" 식 총평을 AI 호출 없이 결정론적으로 계산 — 총평이 개별 판정과 항상 일치하도록 보장.
verifyPipeline.js카카오 채널과 검증 API(v1)가 공유하는 백그라운드 검증 실행 함수(runVerificationJob). 캐시 확인 → 추출·검증 → 저장까지 한 번에 처리.
resultsStore.js검증 결과를 id로 저장/조회하는 메모리 저장소. 카카오 링크, API 폴링(GET /v1/verify/:id), 관리자 대시보드가 공유해서 쓴다.
verifyCache.js완전히 동일한 텍스트 재검증을 막는 캐시. SHA-256 해시 키, 7일 TTL. 원문 자체는 저장하지 않고 결과만 저장한다.
usageStore.js웹사이트(IP 기준) + 카카오(사용자 id 기준) 공용 사용량 관리. 하루 무료 5회 + 초과 시 토큰(1개=100원) 차감. 날짜가 바뀌면 무료 횟수만 리셋, 토큰은 이월.
chatHistory.js카카오 채널 사용자별 최근 대화(최대 12턴) 기억 — 스킬 요청이 원래 무상태(stateless)라 대화가 이어지는 것처럼 보이게 한다.
coupang.js쿠팡파트너스 Open API 딥링크 생성(HMAC-SHA256 서명). 키 미설정 시 일반 검색 링크로 자동 폴백.
kakaoWebhook.js카카오 i 오픈빌더 스킬 서버 핸들러. "검증"/"팩트체크" 트리거 시 검증 파이프라인 + 대시보드 링크, 그 외에는 일반 대화 응답.
renderResultPage.js카카오톡 등으로 공유되는 결과 페이지(/r/:id)의 서버 렌더링 HTML. React 앱과 별개의 정적 페이지지만 동일한 색상·마크업으로 시각적 일관성을 유지.
apiKeys.js검증 API(v1) 키 발급·검증·일일 호출량 관리. 데모 발급이라 가입/결제 절차 없이 즉시 키가 나온다.
apiV1.js외부 개발자가 호출하는 공개 검증 API 라우터(/v1/*). 본 문서 4장에서 상세히 다룬다.
adminAuth.js관리자 대시보드 인증 미들웨어. ADMIN_SECRET 환경변수 또는 서버 기동 시 자동 생성되는 임시 키로 보호.
adminApi.js관리자 통계 API(/api/admin/stats) — 웹/카카오 사용자 수, API 키 목록, 캐시·결과 저장소 현황을 한 번에 반환.
renderAdminPage.js관리자 대시보드 페이지(/admin)의 서버 렌더링 HTML + 조회용 클라이언트 스크립트.

4. 유메 검증 API (v1)

외부 서비스가 유메의 팩트체크 엔진을 직접 호출할 수 있는 공개 API입니다. 웹사이트가 쓰는 내부 /api/verify(SSE 스트리밍, 세션 기반)와는 완전히 분리되어 있으며, API 키 인증과 폴링(polling) 방식으로 동작합니다.

4.1 인증

모든 /v1/* 요청(키 발급 제외)에는 X-API-Key 헤더가 필요합니다. 키가 없다면 아래 발급 엔드포인트로 즉시 데모 키를 받을 수 있습니다(가입·결제 없음).

4.2 엔드포인트

MethodPath설명
POST/v1/keys데모 API 키 발급
POST/v1/verify텍스트 검증 요청 (비동기 — id를 즉시 반환)
GET/v1/verify/:id검증 결과 조회 (폴링)
GET/v1/usage내 API 키의 오늘 호출량 조회
GET/v1/API 개요 JSON (엔드포인트 목록)

POST /v1/keys — 데모 키 발급

curl -X POST https://yume-production-0788.up.railway.app/v1/keys \
  -H "Content-Type: application/json" \
  -d '{"label":"우리 서비스 이름"}'

응답:

{
  "apiKey": "yume_demo_a0fb6bca3e205d2bc6aab1788282a848",
  "label": "우리 서비스 이름",
  "dailyLimit": 200,
  "note": "데모 키입니다 — 실제 결제 없이 즉시 발급되며, 서버 재배포 시 초기화될 수 있어요."
}
IP당 발급 가능한 데모 키 수는 남용 방지를 위해 제한되어 있습니다(최대 10개).

POST /v1/verify — 검증 요청

curl -X POST https://yume-production-0788.up.railway.app/v1/verify \
  -H "X-API-Key: yume_demo_xxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"text":"비타민 C를 하루 10g 이상 섭취하면 감기를 완전히 예방할 수 있다"}'

검증에 보통 10~30초가 걸리므로, 이 요청은 결과를 기다리지 않고 id를 즉시 반환합니다(HTTP 202). 이미 동일한 텍스트가 캐시돼 있다면 곧바로 완료된 결과를 반환합니다(HTTP 200).

// 아직 처리 중일 때 (202)
{ "id": "5a96d1ca6994", "status": "pending", "pollUrl": "/v1/verify/5a96d1ca6994", "usage": {...} }

// 캐시 히트일 때 (200)
{ "id": "5a96d1ca6994", "status": "done", "cached": true, "result": { ... }, "usage": {...} }

GET /v1/verify/:id — 결과 조회 (폴링)

curl https://yume-production-0788.up.railway.app/v1/verify/5a96d1ca6994 \
  -H "X-API-Key: yume_demo_xxxxxxxxxxxxxxxx"
{
  "id": "5a96d1ca6994",
  "status": "done",
  "input": "비타민 C를 하루 10g 이상 섭취하면 감기를 완전히 예방할 수 있다",
  "result": {
    "overall_domain": "의료",
    "summary": "일부 사실과 다른 주장이 포함되어 있습니다.",
    "overall": { "label": "일부 틀림", "detail": "...", "tone": "false" },
    "claims": [
      {
        "text": "비타민 C 하루 10g 이상 섭취 시 감기를 완전히 예방할 수 있다",
        "domain": "의료",
        "verdict": "false",
        "explanation": "...",
        "sources": [ { "title": "...", "url": "..." } ]
      }
    ],
    "related_products": [ { "keyword": "비타민C", "reason": "...", "url": "...", "isAffiliate": true } ]

결과가 아직 준비되지 않았다면 status: "pending"과 result: null이 반환됩니다. 보통 3~5초 간격으로 재조회(폴링)하는 것을 권장합니다.

4.3 오류 응답

상태 코드상황
400text 필드 누락/빈 값
401API 키 누락 또는 유효하지 않음
404존재하지 않거나 만료된 결과 id
429일일 호출 한도(기본 200회) 초과, 또는 키 발급 IP 한도 초과

4.4 요금 모델 (기획)

현재는 데모 단계로 모든 키가 하루 200회 무료 한도만 적용됩니다. 정식 출시 시 호출량 기반 종량제(예: 1,000건당 과금)로 전환할 계획이며, 이 경우 server/apiKeys.js의 메모리 저장을 실제 결제 연동 + DB로 교체합니다.

5. 관리자 대시보드

사이트 운영자가 웹/카카오/API 사용 현황을 한 화면에서 확인하는 내부 전용 페이지입니다.

항목내용
접속 주소/admin
인증관리자 키 (환경변수 ADMIN_SECRET, 미설정 시 서버 기동 로그에 임시 키 출력)
확인 가능 정보웹 무료 사용자 수(IP 기준)·오늘 무료 사용 횟수·토큰 보유 총량, 카카오 대화중 사용자 수, 발급된 API 키 목록과 호출량, 최근 검증 요청 목록, 최근 캐시된 검증 요약
이 페이지는 사용자 IP, 발급된 API 키(마스킹), 검증 요청 내용 미리보기 등 민감한 운영 정보를 보여줍니다. ADMIN_SECRET을 반드시 추측하기 어려운 값으로 설정하고 외부에 공유하지 마세요.
