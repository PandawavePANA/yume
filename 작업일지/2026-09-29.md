## 2. 유메 — 개인

- **본인확인은 돈이 움직일 때만.** 가입 직후 인증 창을 없앴다. 무료 3회는 확인 없이 쓰고, 크레딧을 쓰기 시작하거나 결제할 때 창이 뜬다(마치면 누른 확인이 그대로 이어짐).
- 대신 **보상은 확인된 계정만**: 추천 크레딧, 공헌도(분기 보상), 제보(바운티), 정정 — 이메일만 바꿔 만든 계정이 쌓지 못하게. 보상 버튼을 누르면 그 자리에서 인증 창을 연다.
- 결과 화면에 **"틀린 부분을 AI에게 다시 물어보기(복사)"** — 틀린 주장과 근거를 한 문단으로 복사.
- 결과 공유 링크에 **공유한 사람의 추천 코드**가 실린다. 받은 사람이 "직접 확인해보기"로 가입하면 추천이 잡힌다.
- `?open=api` — 기업용 페이지·점검 보고서의 "체험 키 받기"가 가입 후 바로 API 키 화면으로 잇는다.
- 유료 이용권 **끝나기 3일 전 안내 + 연장하기**(자동 갱신이 없어서).

- 교차 출처 허용 목록을 합치도록 고쳤다 — 문의 API가 기업용 사이트에서 조용히 막혀 있었다.

## 4. 모션

"문서를 검토하는 손"을 한 벌의 언어로.

- 바탕이 **괘선지**. 스크롤의 0.35배로 흐르고, 빨리 내리면 그 속도만큼 기울고, 색이 이야기를 따라 보라 → 주홍 → 보라 → 초록으로 바뀐다.
- 위쪽 **읽은 만큼 레일**. 끝까지 읽으면 체크가 그려진다.
- **대표 장면: 스크롤로 돌리는 팩트체크.** 화면에 붙은 채 스크롤 거리가 재생 위치다. 빛이 답변을 훑고 → 주장 셋에 밑줄 → 맞는 조문 초록 형광펜, 틀린 기한 빨간 줄 + 정정(민법 제766조), 없는 사건번호는 글자가 흩어짐 → "대부분 부정확" 도장. 앱에는 도구 아래 짧은 판.
- 결과: 판정이 **도장으로 찍히고**(앱에서는 짧은 진동), 주장 표시(✓ ✕ ?)가 **펜으로 그려지고**, 확인 수가 굴러 올라감.
- 기다리는 동안: 스피너 대신 **문서를 훑는 빛**, 주장이 찾아질 때마다 여백에 점.
- 히어로 두 줄이 스크롤에 서로 반대로 비켜남, "로 확인하세요"에 형광펜, 세 단계 카드를 잇는 선이 스크롤만큼 그어짐, 원인 카드가 마우스를 따라 기울고 빛이 비침, 마지막 버튼이 자석처럼 끌림, "확인하고"에 빛이 지나감.
- 전부 transform·opacity·배경만 움직인다. "움직임 줄이기"를 켜면 완성된 정지 화면.
- 고친 것: 예전 히어로 물빛이 **한 번도 보이지 않았다** — 페이지 바탕이 그 위를 칠하고 있었다.
