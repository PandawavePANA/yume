# 크롬 웹스토어 등록 — 그대로 붙여넣는 문서

개발자 대시보드의 칸 이름 순서대로 적었습니다. 복사해서 붙이면 됩니다.

---

## 항목 이름
```
유메 — AI 답변 팩트체크
```

## 간단한 설명 (132자 제한)
```
ChatGPT·클로드·제미나이의 답변을 그 자리에서 확인합니다. 판례·법령은 법제처 공식 자료와 직접 대조합니다.
```

## 자세한 설명

```
AI는 존재하지 않는 판례와 논문을 실재하는 것처럼 지어냅니다. 말투가 확신에 차 있어서
읽는 쪽에서는 구분할 방법이 없습니다.

이 확장 프로그램은 ChatGPT·클로드·제미나이·퍼플렉시티의 답변 옆에 「유메로 확인」
버튼을 붙입니다. 누르면 그 답변이 유메 입력칸으로 넘어갑니다.


■ 복사해서 옮길 필요가 없습니다

답변을 드래그해 복사하고, 탭을 옮기고, 붙여넣는 과정이 사라집니다. 버튼 하나입니다.


■ 화면에 있는 글을 그대로 가져옵니다

캡처를 읽는 방식은 글자를 잘못 읽을 수 있고, 공유 링크는 서버에서 열리지 않습니다.
이 확장은 화면에 이미 있는 글을 그대로 가져오므로 틀릴 여지가 없습니다.


■ 사이트가 바뀌어도 쓸 수 있습니다

답변마다 붙는 버튼과, 글을 드래그하면 뜨는 버튼 두 가지가 있습니다. AI 사이트의
화면 구조가 바뀌어 첫 번째가 안 보이더라도 드래그하면 그대로 동작합니다.
오른쪽 버튼 메뉴로도 쓸 수 있어서, 목록에 없는 사이트에서도 됩니다.


■ 글을 서버로 보내지 않습니다

가져온 글은 브라우저 안에만 잠시 담겼다가 유메 탭에서 꺼내 쓰는 즉시 지워집니다.
5분이 지나면 쓰지 않고 삭제합니다. 이 확장이 스스로 어딘가로 보내는 데이터는 없습니다.

유메 입력칸에 넣은 채로 멈추기 때문에, 무엇이 검증될지 먼저 보고 직접 누르게 됩니다.


■ 유메는 이렇게 확인합니다

· AI 답변에서 검증할 수 있는 사실 주장만 골라냅니다
· 법률 주장은 법제처 국가법령정보 공동활용 API를 조회해 조문·판례 원문과 대조합니다
· 인용된 판례·법령·논문이 공식 자료에 없으면 "없다"고 판정합니다
· 확인하는 과정이 실시간으로 보입니다

판정 방식은 특허 출원했습니다.

판정은 참고 정보이며 전문가의 자문을 대신하지 않습니다.

──
만든 곳: 리머 (d-reamer.com)
서비스: yume-reamer.com
```

## 개인정보 보호 탭 — 여기서 대부분 반려됩니다

### 단일 목적 (Single purpose)
```
AI 챗봇의 답변을 사용자가 유메 팩트체크 서비스로 보내 사실 여부를 확인할 수 있게 합니다.
```

### 권한 사용 사유

**storage**
```
사용자가 선택한 답변 글을 유메 탭으로 전달하기 위해 기기 내부에만 일시 저장합니다.
URL 쿼리로 전달하면 길이 제한에 걸리고 해당 글이 브라우저 방문 기록과 서버 접속 로그에
그대로 남기 때문에, 기기 안에만 두고 사용 즉시 삭제합니다.
```

**contextMenus**
```
마우스 오른쪽 버튼 메뉴에 "유메로 확인" 항목을 추가합니다. 지원 목록에 없는 사이트에서도
선택한 글을 보낼 수 있게 하는 경로입니다.
```

**scripting**
```
지원 목록에 없는 사이트에서 사용자가 오른쪽 버튼 메뉴를 실행했을 때, 해당 탭에만
선택 영역을 읽는 스크립트를 주입합니다. 사용자의 명시적 동작 없이는 주입하지 않습니다.
```

**activeTab**
```
사용자가 도구 모음 아이콘을 클릭했을 때 현재 탭의 선택 영역을 읽습니다.
```

**호스트 권한 (chatgpt.com, chat.openai.com, claude.ai, gemini.google.com, perplexity.ai)**
```
해당 사이트의 AI 답변 옆에 "유메로 확인" 버튼을 표시하고, 사용자가 그 버튼을 눌렀을 때
해당 답변의 텍스트를 읽기 위해 필요합니다. 계정 정보, 쿠키, 대화 기록에는 접근하지 않으며
사용자가 버튼을 누르지 않으면 어떤 내용도 읽지 않습니다.
```

**호스트 권한 (yume-reamer.com)**
```
전달받은 텍스트를 유메 입력창에 채워 넣기 위해 필요합니다.
```

## 스크린샷 — 이것만 직접 하셔야 합니다

1280×800 또는 640×400, 최소 1장 (5장까지).

확장을 설치하고 **ChatGPT에서 실제로 쓰는 장면**을 찍어야 합니다. 제가 대신 만들면
남의 서비스 화면을 흉내 낸 이미지가 되어서, 그건 스토어 정책 위반입니다.

찍으면 좋은 장면 순서:
1. ChatGPT 답변 아래 「유메로 확인」 버튼이 보이는 화면
2. 버튼을 눌러 유메 입력칸에 글이 들어온 화면
3. 유메 검증 결과 화면
4. 글을 드래그했을 때 뜨는 버튼

Windows는 `Win + Shift + S`로 영역을 찍으면 됩니다. 크기가 안 맞으면 보내주시면
1280×800으로 맞춰 드리겠습니다.
